## Rules & Behavior Summary
- `ItemConsumeAction`: Gates Harmony/Refine stones (`14:42..44`) behind `SeasonPlanPlugIn` (`SeasonFeatureGate.Harmony`), dispatches `TalismanPlugIn` stat items first, falls back through item strategy -> scroll skill strategy -> `ConsumeEffect`, invokes `IItemConsumingPlugIn` / `IItemConsumedPlugIn`, and updates durability/destruction.
- `ItemModifyConsumeHandlerPlugIn`: Blocks jewel upgrades on equipped slots (`<= LastEquippableItemSlotIndex`) as anti-desync safety.
- Jewel handlers match S6/S9 base rates (`Bless=100%`, `Soul=50%/75%`, `Life=50%`, `Harmony=60%`, `LowerRefine=20%`, `HigherRefine=80%`), and `RefineStoneUpgradeConsumeHandlerPlugIn` guards `MinimumPhysBaseDmg < MaximumPhysBaseDmg`.
- `FruitConsumeHandlerPlugIn` & `ResetFruitConsumeHandlerPlugIn`: Require Lv10+, empty equipment slots, enforce fruit cap and return points to `LevelUpPoints`.

## Bugs, Discrepancies & Gaps Found
1. **Durability consumed before failure in `TownPortalScrollConsumeHandlerPlugIn.cs:31-42`**: Calls `base.ConsumeItemAsync` (decrementing `item.Durability`) *before* verifying that `targetMapDef` / `SafeZoneSpawnGate` exists. If the warp target is unavailable, it returns `false` with `item.Durability` already decremented out of sync.
2. **Inconsistent `RequiredItemLevel` pre-check in `ItemUpgradeConsumeHandlerPlugIn.cs:105-108,207-215`**: `ItemCanHaveOption` does not filter `LevelDependentOptions` by `ldo.RequiredItemLevel <= item.Level`, whereas `TryAddItemOptionWithSettings` filters on `RequiredItemLevel <= item.Level` *after* rolling `Rand.NextRandomBool(successChance)`. If the roll fails, the jewel is consumed on an ineligible low-level item; if it succeeds, `possibleOptions` is empty and returns `false`.
3. **Misleading `else` branch in `SiegePotionConsumeHandlerPlugIn.cs:37-49`**: `if (item.Level == 1 ...)` is not `else if`, so a level-0 Potion of Bless that fails `ConsumeItemCoreAsync` falls through to the level-1 `else` branch and incorrectly emits `ItemEffectNotFound`.
4. **Potion cooldown `500ms` vs S6/S9 `100ms`**: `RecoverConsumeHandlerPlugIn` / `ShieldPotionConsumeHandlerPlugIn` / `ElitePotionConsumeHandlerPlugIn` default `CooldownTime` to `0.5s`, whereas S6/S9 `IGC_Common.ini` sets `PotionDelayTime = 100` ms.
5. **`AntidoteConsumeHandlerPlugIn.cs:31-38` removes at most one effect**: Uses `else if` between Poison (`0x37`) and Ice (`0x38`), so if both debuffs are active simultaneously, only Poison is cleared.
6. **`BlessJewelConsumeHandlerPlugIn` `RepairTargetItems` empty by default**: Requires configuration for pets (e.g. Fenrir repair via Bless if enabled).
7. **Unverified Lucky Item jewel block**: `UpgradeItemLevelJewelConsumeHandlerPlugIn` only checks `CanLevelBeUpgraded()` and `AllowedItems`/`DisallowedItems` (S6/S9 `AllowEnchantLuckyItemByJewels = 0`).
