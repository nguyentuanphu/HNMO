## Bugs Found & Fixed During Integration & Live Playtest
1. **#17 (`origin/antigravity-host-settings`) — Fresh PostgreSQL schema role overwrite & `Username=` normalization (`3a5899ef`)**:
   - `NpgsqlConnectionStringBuilder.ToString()` normalized `"User Id="` to `"Username="` and `ApplyHostSettings` overwrote per-schema roles (`config`, `account`, `friend`, `guild`) with `postgres`. During fresh database creation, `ConnectionConfigurator.GetRoleName` failed to parse `"Username="`, emitting invalid `CREATE ROLE  WITH LOGIN PASSWORD ...` SQL.
   - **Fix**: Preserved non-`postgres` per-schema roles in `ConfigFileDatabaseConnectionStringProvider.ApplyHostSettings`, parsed both `User Id` and `Username` via `NpgsqlConnectionStringBuilder` in `ConnectionConfigurator`, and pushed the fix to `#17` (`a3f5d42a`).
2. **#17 (`origin/antigravity-host-settings`) — Bridge CLI overrides & custom `ConnectServerPort` propagation (`2633b4c9`, `b4fdfd14`, `66ee48c4`)**:
   - `HostSettingsStore.LoadOrMigrate` in `client/web/bridge/Program.cs` was overwriting explicit `--Launcher:Enabled=false`, `--Launcher:SavePath`, and `--HNMO:WebRoot`/`DataPath`/`VendorPath` overrides; `Portal.WebsiteSettingsAsync` and `client/web/src/main.ts` did not propagate configured `ConnectServerPort` from `HostSettings` to the browser login form.
   - **Fix**: Honored explicit CLI overrides, served `connectServerPort` from `/website/settings`, updated `ConnectServerContainer` to honor `HostSettings.ConnectServerPort`, and pushed to `#17` (`a3f5d42a`).
3. **#13 (`origin/antigravity-web-login-ticket`) — Packet renumbering + crash on `F5 24` ticket login**:
   - Renumbered `HnmoTicketLogin` from `F5 23` to `F5 24` in XML, regenerated server C# + TS + packet docs, and pushed to `#13` (`1d989b54`).
   - Live playtest via `#playNowButton` (`F5 24`) hit `System.InvalidOperationException: Collection was modified` in `ViewPlugInContainer.OnClientVersionChanged` because `HnmoTicketLoginHandlerPlugIn` unconditionally replaced `RemotePlayer.ClientVersion` with `(106, 3, Invariant)` (changing language from `English` to `Invariant`) while `ViewPlugInContainer.ActivePlugIns` was enumerated live during deactivation.
   - **Fix**: Only set `RemotePlayer.ClientVersion` on ticket login when `default`, and snapshot `ActivePlugIns.ToList()` / `KnownPlugIns.ToList()` in `ViewPlugInContainer.OnClientVersionChanged` and `PacketHandlerPlugInContainer.OnClientVersionChanged`. Pushed fix to `#13`.
4. **#36 (`origin/antigravity-combining-leftovers`) — Unescaped XML entity (`ee662be5`)**:
   - Fixed unescaped `&` in `HnmoLeftoversState` XML documentation in `ServerToClientPackets.xml` (eliminating `CS1570` warnings) and pushed to `#36` (`e4007feb`).
