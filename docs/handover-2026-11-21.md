## The owner's rules

1. **One extra agent at a time.** Run at most one extra agent (subagent) besides yourself, and queue the rest.
2. **Ask with a popup.** Put owner decisions in a popup (AskUserQuestion) with the recommended option first. When the
   classic MU rule is unclear, ask instead of guessing.
3. **No third-party names.** Code, comments, docs, test and file names, commits and PRs never name a third-party
   server suite, publisher or project. Say "the Season 6 / Season 9 server suites", "legacy server files" or
   "classic MU".
4. **One bug, one draft PR.** Each bug gets its own DRAFT PR into `claude/hnmo-main-handover-54co2m`, with a test that
   fails before the fix and passes after.
   - Branch from a fresh `origin/claude/hnmo-main-handover-54co2m`.
   - Don't commit `server/src/Web/Map/wwwroot/js/HNMO.Web.Map.js`: builds rewrite its line endings.
   - Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
   - PR bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
5. **Keep the owner's PC light.**
   - On the PC, run every build, test or browser probe through
     `powershell -File D:\WorkSpace\meshy\tools\heavy.ps1 <command>`. It queues heavy jobs one at a time.
   - Use long options (`--configuration`), and set dotnet in `PATH` and `DOTNET_ROOT`.
   - In a fresh checkout, build `server/src/Persistence/SourceGenerator` (Debug) first.
6. **Main's areas.** Main owns walk-resume (`client/web/src/online.ts`), the Season 9 world names, the website and
   releases. Bugs there go into one report. The next free F5 code is 56. Update plug-ins that read saved plug-in
   settings strip `$id` / `$values` first.

## What only the owner's PC has

- The demo game server, the web bridges and the browser probes. Their scripts are in `tools/local-checks/`.
- The legacy Season 6 / Season 9 server files (read-only; never copied into the repository). The explicit test
  `ServerImporterRealServerTrial` needs them; with none, it is skipped.

A cloud session can do the code audit, the tests and the PRs. The browser sweeps, the suites against a running game
