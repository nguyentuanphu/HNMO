HNMO Control

How to use this page

This local control page manages the database, game server, web game, backups, auto-start, and updates. It is only reachable from this computer.

First-start setup wizard

After starting HNMO, open Admin panel (/users) to create your first admin user (password >= 12 characters), then create an Administrator API key on /api-keys for Website Portal registration.
