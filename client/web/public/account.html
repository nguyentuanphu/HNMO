Finish the setup (host only)

Registration needs a key for the game server, once:

1. Open the admin panel and create the first user.
2. Open API keys, create a key with the role Administrator and copy it.
3. Paste it here. This only works on the host computer.

Create an account

New accounts get free cash shop coins.

Gift code

Enter a gift code for one of your characters: coins go to the account, zen and items to the character (they arrive in its bag when it's in the game). In the game you can also type /code CODE.

Gift codes can't be entered on the website on this server: use /code CODE in the game.

Resets and stats

Reset or relife your characters, add or clear stat points and switch the delegated reset (the server resets your character while it's offline leveling). Changes need the account out of the game (and not offline leveling). Days are Sydney days.

The reset system is switched off on this server.
