# Season 6 Events & Exchanges (`/s6-events`)

Disabled by default. Includes:

- **Last Man Standing (`/lms`)**: Scheduled Sydney-time (plus manual "Start LMS Now" trigger) PvP elimination arena event integrated into Timetable and Event Alerts / Discord, with `MissionCoinGranter` coin payouts and queued owed-reward item/Zen delivery.
- **Cherry Blossom Spirit Exchange (NPC `#450` / `/blossom`)**: Consumes stacked Golden Cherry Blossom Branches (`10`, `50`, `255`) for weighted buffs, Zen, coins, and items.
- **Delgado Lucky Coin Exchange (NPC `#478` / `/luckycoin`)**: Consumes stacked Lucky Coins (`10`, `20`, `30`) for weighted Zen, coins, and jewel rewards.
