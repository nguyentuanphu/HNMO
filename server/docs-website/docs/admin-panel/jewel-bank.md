# Jewel bank & clearing master skills

The **Jewel bank** lets players store loose jewels (`Bless`, `Soul`, `Life`, `Creation`, `Chaos`, `Harmony`, `Guardian`, or admin-added jewels) as account-wide numbers, withdraw them in-game (`F7`) or via the website, and reset/refund spent **Master skill points**.

## Configuration (`/jewel-bank`)

1. Turn on **Enable Jewel Bank** (off by default).
2. Configure **Deposit Zen fee**, **Withdraw Zen fee**, and safe-zone requirement.
3. Add, enable/disable, or edit **Max/account** capacities for any jewel `(Group, Number)`.
4. Configure **Clear master skill points** fees (`Clear master (Zen)`, `Coins`) both here (for in-game `F7` / `/clearmaster`) and on **Resets & relife** (for offline website resets alongside stat clearing).
