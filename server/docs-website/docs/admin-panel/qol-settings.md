# QoL Commands & Mining (`/qol-settings`)

Disabled by default. Includes:

- **`/lock <PIN>` & `/unlock <PIN>`**: Re-locks or unlocks second-password protections mid-session (`AccountSafety`).
- **`/requests <on|off>`**: Auto-refuses incoming Trade, Party, and Duel requests cleanly with EN/VI caller notices.
- **`/srvinfo`**: Prints live server EXP, Drop, Zen multiplier, max Life `+Option` cap, and account coins.
- **`/mine`**: Cooldown-based excavation mini-system with optional Mining Pick item requirement and weighted Zen/Jewel rewards.
- **Personal Store Multi-Currency UI**: Selecting Coins (`WCoinC`/`WCoinP`/`GoblinPoints`) or Jewels cleanly sends `PlayerShopSetItemPriceExtended` based on server `PlayerShopPriceTypesExtended`.
