# Player Rankings & Bulk Add Stats (`/rankings-settings`)

The **Player Ranking & Add Stats** plug-in (`PlayerRankingPlugIn`, packets `F5 46` / `F5 47`, `/rank`) powers two in-game windows in the web client:

- **Player Rankings (`Shift+R` or `/rank`)**: Shows Top Characters (Resets, Master Level, Level, Online status), Top Online Players, Top Guilds, and Mini-Game Event leaderboards, plus the player's own rank.
- **Bulk Add Stats (`Shift+A` or `+ Add Stats` beside Character Window `C`)**: Lets players distribute dozens, hundreds, or thousands of Level-Up Points across Strength, Agility, Vitality, Energy, and Command in one click with live preview and server validation.

Administrators can toggle either window, show/hide individual leaderboard tabs, change Top N size (`5..100`), and adjust database cache seconds from `/rankings-settings`.
