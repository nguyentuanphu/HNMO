# Rate & Balance Tuning (`/rate-tuning`)

Disabled by default. Allows hosts to customize:

- **Jewel of Soul**: Base success percentage and Luck bonus percentage.
- **Jewel of Life & Option Cap**: Base success percentage and max Life `+Option` tier (`4` = `+16 / 4%` classic or `7` = `+28 / 7%`).
- **High Chaos Mix Global Announcement**: Gold server broadcast when an upgrade reaches `+15` (configurable `+10..+15`).
- **Zen Drop Multiplier**: Server-wide monster Zen drop percentage (`10..1000%`).
- **Per-Class PvP & PvM Damage Multipliers**: Independent scaling percentages for all 7 base character lines.
